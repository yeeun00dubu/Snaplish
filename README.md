# Snaplish

윈도우 노트북에서 영어 문장을 캡처하면 번역 알림이 뜨는 프로그램입니다. 폰에서는 실행되지 않습니다.

## 실행 방법

1. [Python 3](https://www.python.org/downloads/)를 설치합니다. 설치 첫 화면에서 **Add python.exe to PATH**를 켭니다.
2. 이 저장소를 내려받아 압축을 풉니다.
3. `캡처감지 켜기.bat`을 더블클릭합니다. 검은 창은 끄지 않습니다.
4. 브라우저에서 http://127.0.0.1:8765 를 엽니다.
5. `Win + Shift + S`로 영어 문장 부분만 캡처합니다. 오른쪽 위에 번역 카드가 뜹니다.

자세한 사용법과 문제 해결은 `실행가이드.md`에 있습니다.
